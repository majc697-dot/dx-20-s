# DX-20S 行车安全信息终端 — 简明使用指南

> 本指南面向日常使用本设备的操作者，用最直白的语言说明"它是什么、怎么看、怎么用、出问题怎么办"。
> 更多逐项功能的细化说明，可参考同目录下的《DX-20S 用户说明书》。

---

## 一、它是什么

DX-20S 是一台放在驾驶室里的**行车安全信息终端**。它的工作很简单：

- 自动接收由运指中心（指挥调度一方）发来的**前方安全信息**；
- 在屏幕上清晰地显示出来，并配合声音、震动提醒您；
- 帮您提前知道前方哪里要限速、哪里有人在作业、需要注意什么。

您不需要做任何复杂的设置，通电后它就会默默工作，把重要的运行提示送到您眼前。

日常操作只需要用到机身正面的**四个按键**，所有功能都能用它们完成。

---

## 二、机身与按键

设备正面是一块彩色显示屏，下方有四个实体按键，从左到右依次是：

| 按键 | 平时用来 | 在菜单里用来 |
|------|----------|--------------|
| 左键（上） | 向上选择 / 翻看上一条信息 | 向上移动光标 |
| 确认键（中上） | 进入菜单 / 打开一条信息 | 选中、确认 |
| 右键（中下） | 返回 / 退出 | 返回上一级 |
| 下键（下） | 向下选择 / 翻看下一条信息 | 向下移动光标 |

> 小提示：屏幕最下方通常会显示三到四个小字母，它们就是在提示您"此刻按哪个键能做什么"。比如 `[K]` 表示按确认键，`[C]` 表示按右键返回，`[X]` 表示按左键。看屏幕底栏就知道下一步怎么操作。

---

## 三、开机、关机与充电

**开机**
- 长按任意键或电源键（视机身标注），屏幕亮起即进入工作状态。
- 如果电量不足，设备会拒绝开机，请先接上充电线。

**关机**
- 在菜单中找到"工具箱"，选择关机；或直接长按电源键。
- 当电量很低时，设备会自动关机以保护电池，请尽快充电。

**充电**
- 使用标配充电线连接电源即可。屏幕右上角会显示电池图标，充电时图标旁会出现闪电符号和当前电压。
- 电量低于一定程度时，电池图标会变红提醒；低于更危险的程度会显示红叉，请立即充电。
- 建议在非运行时段及时补电，避免中途没电。

## 四、主屏幕怎么看

设备平时停在主屏幕，分上、中、下三个区域：

**顶部一行（状态栏）**
- 左侧：当前日期、星期、时间。
- 右侧：信号格（越多表示接收越好）、电池图标（含电量或电压）。
- 中间可能显示"上行 / 下行"等方向信息，以及当前运行线路。

**中间大块（信息区）**
- 没有新信息时：显示"正在接收"或类似的待机提示，请您放心，它一直在监听。
- 来信息时：这里会完整显示一条运行提示，内容包括：
  - **运行编号**（如 G1234、D2001）—— 这条信息对应的车次；
  - **方向**（上行绿色 / 下行红色）—— 朝哪个方向生效；
  - **速度 / 限速** —— 前方需要注意的速度；
  - **里程位置** —— 信息生效的地点（用里程表示）；
  - **运行线路** —— 在哪条线上；
  - **车头编号** —— 本车对应的编号；
  - **时间** —— 信息发出或生效的时间。
- 您可以根据颜色快速判断：绿色通常表示上行，红色通常表示下行，让您一眼分清方向。

**底部一行（操作提示栏）**
- 用三个小字母告诉您现在按哪个键能做什么，例如：
  - `[K]` 确认键：查看 / 进入；
  - `[C]` 右键：返回 / 退出；
  - `[X]` 左键：翻看历史 / 其它快捷操作。

## 五、信息来了，怎么处理

当一条新的运行提示出现时：

1. **先看方向和地点**：通过颜色（绿=上行，红=下行）和里程位置，确认是不是和本车相关。
2. **看清速度和注意事项**：按提示控制好速度、留意前方作业或限速区段。
3. **确认收到**（可选）：在信息界面按提示键进行"已读确认"，避免重复打扰。
4. **回看历史**：如果您错过了或想再看看之前的信息，按左键进入"回看"，可以一条条往前翻；屏幕会显示"回看 第几条 / 共几条"。

> 如果屏幕上出现看不懂的乱码、整行星号（`********`）或 `<NUL>` 字样，说明这条信息接收不完整或格式异常，请以其它的方式再次核实，不要据此操作。

## 六、最常用的几个调整

这些功能都在"功能菜单"里，用确认键进入、上下键选择、确认键打开：

**1. 提示方式（声音 / 震动）**
- 可以设置：只响、只震、又响又震、或静音。
- 还可以选择提醒的时长（短促或长一点）。
- 夜间或需要安静时，建议设为"只震动"或"静音"。

**2. 屏幕亮度**
- 有多档亮度可调，光线强时调亮，夜间调暗更舒适、也更省电。

**3. 自动熄屏**
- 可设置一段时间不操作后屏幕变暗或关闭，再次按键即亮起，省电又不耽误事。

**4. 画面风格（换肤）**
- 提供几种不同的配色主题，您可挑选看着最舒服的一款。

**5. 时间**
- 设备会自动保持时间；如需要，可在菜单里手动调整年、月、日、时、分。

## 七、信息筛选（只看关心的）

为了避免无关信息打扰，您可以设置筛选条件，让设备只重点提示与您相关的内容：

- **按运行线路筛选**：只关注您当前所在的线路。
- **按方向筛选**：只关注上行或下行。
- **按类型筛选**：只关注特定类别的提示。

筛选打开后，不符合条件的信息会被弱化或跳过，符合的会被正常提醒。
如果某天想"全部都看"，把对应筛选关掉即可。

---

## 八、功能菜单一览（通俗版）

按确认键进入主菜单，里面大致分几页，常见项目有：

- **快捷查看**：把您最关心的几种信息设成快捷键，一按就跳到对应内容。
- **信息筛选**：见上一节。
- **提示方式**：声音、震动、时长设置。
- **屏幕亮度** / **自动熄屏**：见第六节。
- **画面风格**：换主题配色。
- **时间设置**：校准时钟。
- **信号质量**：查看当前接收情况（信号格、质量指示）。
- **信息确认**：设置是否需要手动确认收到。
- **运行线路 / 行驶方向 / 车头编号 / 里程位置**：填写或核对本车基本信息，让提示更对得上。
- **关于本机**：查看设备型号、版本等基本信息。
- **系统状态**：查看电量、信号等当前状态。
- **工具箱**：重启设备、清空历史信息、恢复出厂设置等。

> 每一项进入后，屏幕底栏都会提示您"按哪个键确认、按哪个键返回"，跟着提示走就不会错。

## 九、常见问题

**Q：屏幕一直显示"正在接收"，没出过信息，正常吗？**
A：正常。没有新信息时它本就处于待机监听状态，说明一切在正常工作。

**Q：怎么没声音 / 没震动了？**
A：请检查"提示方式"是否被设成了静音，或震动被关闭；也请确认设备没有处于免打扰场景。

**Q：屏幕上时间不对怎么办？**
A：进入"时间设置"手动校准即可；设备平时会自动保持。

**Q：信息看不全 / 看不清？**
A：可调高屏幕亮度，或在"画面风格"里换一个对比更明显的主题。

**Q：想翻看刚才错过的提示？**
A：按左键进入"回看"模式，逐条往前翻即可。

**Q：设备反应变慢或异常？**
A：可在"工具箱"里选择重启；若需彻底清理，可选择清空历史信息。恢复出厂设置会清除您的个性化配置，请谨慎使用。

**Q：电量消耗很快？**
A：高亮度、长亮屏、频繁震动都会更耗电。适当调低亮度、开启自动熄屏可延长使用时间。

## 十、安全与保养

- 请使用标配或合规的充电配件，避免使用来路不明的电源线。
- 设备怕高温：环境过热时它会自动关机保护，待温度降下来再使用。
- 请勿自行拆解、撞击或进水；显示屏为易碎部件，注意保护。
- 本设备是辅助提醒工具，**最终仍以现场实际信号和规章为准**，收到任何提示都应结合实际情况判断。
- 长期不使用时，也请定期充电，避免电池过度放电。
