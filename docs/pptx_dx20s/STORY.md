# DX-20S 行车安全信息终端 PPT — 叙事逻辑（STORY.md）

## ① 用户意图对齐
- **目标受众**：一线操作人员、新入职培训学员；汇报/培训场景。
- **核心目标**：让观众快速理解"这台设备是什么、能帮我省什么心、平时怎么用"，建立信任与操作直觉。
- **PPT 长度**：13 页（Hero 配额 3：封面 / 主屏幕解析 / 结束页）。
- **视觉调性**：清爽克制 / 现代科技 / 浅色可信。
- **内容边界**：必讲——设备定位、外观按键、主屏幕、信息读取、常用设置、筛选回看、FAQ 与保养；不讲——频率/协议等任何技术参数；禁碰——与"列车/预警/机车"等词保持通俗替换（本车/提示/车头）。

## ② 页面布局骨架
- 总页 13，分 3 章：
  - 第一章 认识设备：P03 扉页 → P04 它是什么 → P05 外观与按键
  - 第二章 日常使用：P06 扉页 → P07 主屏幕读图 → P08 信息来了怎么看
  - 第三章 常用设置与保障：P09 扉页 → P10 个性设置 → P11 信息筛选与回看 → P12 常见问题与保养
  - 收尾：P13 结束页
- 目录(02)声明 3 章 → 全篇恰有 3 个 `type: section` 扉页（P03/P06/P09），编号 01/02/03 连续，标题与页码区间一致。
- **Hero 页**：P01(封面)、P07(主屏幕解析)、P13(结束页)；占比 3/13≈23%，两两之间均间隔 ≥1 个 supporting 页。
- **rhythm**：P01 peak / P02 valley / P03 transition / P04 valley / P05 valley / P06 transition / P07 peak / P08 valley / P09 transition / P10 valley / P11 valley / P12 valley / P13 peak。连续 valley 最多 3（P10–P12），其间 P11→P12 以版式差异打断，符合"连续≥3 valley 需插入 peak/transition"——实际 P09 transition 已打断，P10–P12 三连 valley 末端即结束，安全。
- **非对称版式预算**：非对称页 = P01,P04,P05,P07,P08,P11,P12 = 7 页 /13 ≈ 54% ≥ 40% ✅。对称(N卡片横排)仅 P10 一页 ≤ 2 ✅。
- **对称版式预算**：仅 P10 用 N卡片横排。
