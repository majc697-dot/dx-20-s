# DX-20S 行车安全信息终端 PPT — 设计稿（DESIGN.md）

## 0. 设计意图（用户显式指令覆盖）
- 用户明确要求：**浅色背景**。
- 主题：DX-20S 行车安全信息终端（产品介绍 + 使用指南）。
- 受众：一线操作人员 / 培训场景，措辞通俗，避免技术参数。
- 视觉调性：清爽、现代、克制、可信（浅色科技风）。

## 1. 画布与母版（A/B/C 三区）
- 画布：1280 × 720，16:9。
- 安全区 padding：上下 20px、左右 64px。
- **A 标题块** 0–120px：主标题 34px bold，左侧 6px 主色竖条装饰；标题块右侧不塞小图。
- **B 内容区** 120–660px：正文、卡片、配图、SVG 设备示意。
- **C 页脚条** 660–720px：左侧项目名「DX-20S 行车安全信息终端」+ 右侧页码 `NN / 13`（14px，#94A3B8）。
- 封面 / 章节扉页 / 结束页 允许自定义版式（不强制三区）。

## 2. 颜色系统（浅色）
| 角色 | HEX | 用途 |
| :--- | :--- | :--- |
| 背景 BG | `#F7F9FC` | 全篇浅色底 |
| 表面 surface | `#FFFFFF` | 卡片 / 浮起块 |
| 主色 primary | `#2563EB` | 标题竖条、强调块、图标主色 |
| 辅色 secondary | `#0EA5E9` | 次图标、渐变第二色、链接 |
| 强调 accent | `#F59E0B` | 关键数字 / 焦点标注（≤10%，Hero 可至 18%） |
| 文本 text | `#1E293B` | 标题与正文 |
| 次文本 subtext | `#64748B` | 说明、页脚、辅助字 |
| 边框 border | `#E2E8F0` | 卡片描边、分隔线 |
| 设备屏 dark | `#0F172A` | 设备屏幕底色（深色，与浅底形成对比） |

**面积分配**：主色/浅底 ≤ 60%；辅色 ≤ 30%；强调色 ≤ 10%（Hero 页 ≤ 18%）。
**渐变**：`linear-gradient(135deg, #2563EB 0%, #0EA5E9 100%)` 用于封面色块、章节号底、卡片头。
**半透明**：`rgba(37,99,235,0.08)` 大面积浅蓝覆盖；卡片 `boxShadow: '0 4px 18px rgba(15,23,42,0.08)'`。

## 3. 字体系统
- 中文：`'Microsoft YaHei', 'PingFang SC', 'Source Han Sans SC', sans-serif`（系统可用优先）。
- 西文 / 数字：`'Inter', 'Helvetica Neue', Arial, sans-serif`。
- 字号阶梯：
  - 封面主标题 60px bold；章节大字 56px bold。
  - 页面主标题 34px bold；卡片小标题 22px bold。
  - 正文 20–22px regular，行高 1.5；辅助说明 16–18px。
  - 巨型数字 / 锚点 72–96px bold（accent 色）。
  - 页码 / 脚注 14px。

## 4. 信息密度
- 常规内容页留白 ≤ 35%；封面 / 章节 / 结束页留白可至 40%。
- 卡片填充率 ≥ 85%：高卡片正文 ≥ 100 字；尾部标签用 `marginTop: 'auto'` 钉底。

## 5. 配图系统
- **L1 主视觉**（设备示意）：用 **SVG 设备示意图**（圆角 bezel + 深色屏幕 + 三区 UI 文字），作为结构化示意，非照片。用于封面(右)、外观与按键(左)、主屏幕读图(上)、信息读取(右小屏)。统一深色屏 `#0F172A` + 浅色文字，风格全篇一致。
- **L2 支撑图**：FAIcon 图标（32–48px，primary/secondary 着色）用于要点卡锚点。
- **L3 角标**：页码 + 项目名统一在 C 区，全篇一致。
- 不使用 ImageGen（用户未要求生图，且设备为屏幕类终端，SVG 示意更准确可控）；无在线 URL。
- 设备 SVG 方案记录在 §6 配图清单。

## 7. 设备 SVG 示意规范（全篇统一）
- 外形：圆角矩形 bezel，`fill:#2B3445`，`rx:24`；内含屏幕 `fill:#0F172A`，`rx:10`。
- 屏幕三区：顶部状态条（时间/信号格/电池）、中央信息区（车次·方向色块·速度·里程·线路）、底部操作提示 `[K][C][X]`。
- 文字用浅色 `#E2E8F0` / `#93C5FD`（上行绿 `#34D399`、下行红 `#F87171` 反色块）。
- 统一尺寸比例，深色屏与浅色幻灯片背景形成清晰对比。
- 设备示意视为「结构化示意」，非具象摄影，符合 SVG 使用边界。
