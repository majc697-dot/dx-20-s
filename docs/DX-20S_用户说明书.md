# DX-20S 便携防护预警终端 用户说明书

**固件版本：** 20S_V2.1.0_260908C
**制造商：** EagleOwl Tec.（2026）
**适用机型：** DX-20S

---

## 1. 产品概述

DX-20S 是一款便携式铁路列车接近预警接收终端，用于接收机车电台 LBJ 设备通过 CIR 系统在 **821.2375MHz** 频率上发出的列车防护报警信息（POCSAG 协议，1200bps），并实时显示、存储与声光提示，为线路作业人员提供来车预警。

### 1.1 主要功能

- 实时接收并解码 LBJ 预警消息（传统版式 / 新版混合版式 / LBJ 时间消息）
- 最多存储 **2000 条**历史消息，支持快捷查看与逐条回看
- 上/下行方向彩色标识，蜂鸣器旋律区分方向
- 公里标过滤：只对设定距离范围内的列车告警，并可推算到达倒计时
- 多级消息过滤器（空消息 / 未注册机辆 / 旧版消息 / 时间消息 / 弱信号）
- 8 种界面主题，可开关列车类型与信号塔显示元素
- 自动频率校正（AFC），适应机车电台频偏
- 低功耗模式、低电量自动关机保护、高温强制关机

### 1.2 技术规格

| 项目 | 参数 |
|---|---|
| 接收频率 | 821.2375 MHz（FSK 直接解调） |
| 协议 | POCSAG 1200bps，监听地址 1234000 |
| 接收带宽 | 12.5 kHz |
| 频率校正 | 自动（AFC，基于载波/前导码频偏 FEI 测量），可关闭 |
| 显示屏 | 3.2" TFT 彩屏，320×240（横向），ST7789 驱动 |
| 字库 | HarmonyOS Sans SC（HMOS 20px / HMOS_28 28px / UI20） |
| 实时时钟 | 外置 RTC（PCF8563），断电保持时间；无 RTC 时经 NTP 校时 |
| 消息存储 | NVS 闪存，2000 条环形存储 |
| 提示器 | 无源蜂鸣器（PWM 多音调旋律）+ 偏心振动马达 |
| 供电 | 3.3V～4.2V 锂电池，支持充电（插入充电器显示 ⚡ 图标） |
| 按键 | 4 键 AD 分压（K1/K2/K3/K4 共用一路 ADC） |

## 2. 按键说明

机身右侧配有 4 个按键（对应内部 AD 分压值区间）：

| 按键 | AD 区间 | 主界面作用 | 菜单内作用 |
|---|---|---|---|
| **K1** | 650～1000 | 进入功能菜单 | 返回上级 / 退出菜单 |
| **K2** | 1500～2000 | 回看上一条（更旧）消息 | 向上移动选择 |
| **K3** | 2710～3900 | 回看下一条（更新）消息 | 向下移动选择 |
| **K4** | 4000～4096 | 返回实时监听（最新消息） | 确认 / 进入 |

> 每次按键均有操作提示音（受提示模式控制）。按任意键会点亮背光。

## 3. 快速上手

1. **开机**：拨动电源开关，设备播放开机提示音，屏幕点亮，顶栏显示时间、温度，底栏显示 `Init...` 与电量，随后进入 **监听界面**（"等待接收消息……"）。
2. **等待消息**：收到 LBJ 消息后自动切换为消息画面并按提示模式播报。
3. **回看**：按 K2/K3 逐条翻看历史消息；按 K4 回到最新监听状态。
4. **进菜单**：按 K1 进入功能菜单；K2/K3 选择、K4 确认、K1 返回。
5. **关机**：拨动电源开关即可（设备内置电源锁存电路，低电量时会自动关机）。

## 4. 主界面详解

主界面分为**顶栏**、**中部消息区**、**底栏**三个区域。

### 4.1 顶栏

```
2026/10/13 二 20:30            32C
```

- 左侧：`年/月/日 星期 时:分`（星期以 一/二/…/日 显示）
- 右侧：RTC 温度（℃）；当同时开启「公里标过滤」与「显示列车到达时间」时，此处改为显示到达倒计时（如 `  3分42秒`，未计算时为 ` --分--秒`）

### 4.2 中部消息区

**① 监听界面（无消息时）**

- 普通状态：显示 `等待接收消息......`
- 公里标过滤启用时，显示过滤器摘要：

```
[公里标过滤器已启用]
行别条件:  上行, 下行, 接近和离去
位置距离:  1000.0 K [10.0 Km]
等待接收消息......
```

**② 传统消息版式（type 0，旧版 LBJ）**

```
车   次:  57003        ┌────┐
速   度:  68 km/h      │ 上行│ ← 行别色块
公里标:  45.2 K        └────┘
类型: 路用列车
                       ▂▄▆█  -78.4dbm
```

- 行别块：上行=绿色，下行=红色
- 信号塔：5 格信号强度图标（1 格红 / 2～3 格橙 / 4～5 格绿），旁边标注 RSSI（dBm）
- 「类型」与信号塔可通过菜单 [4] 关闭

**③ 新版混合消息版式（type 1，现行主要版式）**

```
车次: G89              ┌────┐
速: 348 km/h  1234.5K  │ 上行│
车: CR400AF-02001
线路: 京广高铁
类型: 直通高速动车组    ▂▄▆█ -78.4dbm
```

- 第三行「车:」显示 `机车型号-注册号后5位`；无机车型号时显示「号: + 完整注册号」

**④ LBJ 时间消息版式（type 2）**

```
LBJ时间: 20:30
```

### 4.3 车次类型识别

设备根据车次字头与编号自动判别列车类型并显示，例如：

| 字头 | 类型示例 |
|---|---|
| G | 直通高速动车组 / 管内高速动车组（含"临"表示临客） |
| D / C | 直通动车组 / 城际动车组 |
| Z / T / K | 直达特快 / 特快 / 快速列车 |
| Y / L / S | 旅游列车 / 临客列车 / 市郊旅客列车 |
| X | 行包列车（中欧班列 8001-8998 等） |
| 0 / F / DJ / JC | 回送 / 折返 / 动检确认车 / 检测列车 |
| 1001～7598 | 直通/管内普通客车、慢车、通勤列车 |
| 10001～79998 | 技术直达、直通货、区段货物、摘挂、小运转、单机、路用、救援等 |
| 80001～89999 | 五定班列、快运、煤炭/石油/始发/空车直达 |

### 4.4 底栏

```
NTP [联动] [K] [C]            [🔋]*
```

- **NTP / RX / WEB**：校时来源与接收状态（未联网时为 RX）
- **提示模式**：`[静音] / [声音] / [震动] / [联动]`
- **[K]**：公里标过滤已启用（青色）
- **[C]**：至少一项条件过滤已启用（橙色）
- **[X]**：自动频率校正已关闭（红色，提示频偏风险）
- **低电量时**：底栏改显 `低电量!`（电压 ≤3.5V 时自动禁用振动防重启）
- **右下角电池图标**：圆角边框 + 电量填充，颜色规则：
  - 电量 ≥40%：绿色；20%～40%：绿框橙色填充；<20%：红色；<5%：红框内打 ✕
  - 图标左侧按「电池栏信息」设置显示电压（如 `4.0V`）、预估电量（如 ` 88%`）或不显示
  - 省电模式开启时，图标右侧显示 `*`
  - 插入充电器时，改为显示 `4.1V⚡`

### 4.5 回看模式

按 K2/K3 进入回看后：

- 顶栏时间前加 `@`，显示该条消息的接收时间：`@ 2026-10-13 20:29`
- 底栏左侧显示 `回看: 0005/2K`（当前条目号/容量 2000）
- 按 K4 退出回看，回到实时监听

以表格形式每页 5 条浏览历史消息，K2/K3 翻页（循环），K4 打开显示模式选择，K1 返回。

五种显示模式（选择后存入 NVS，掉电保持）：

| 模式 | 列 |
|---|---|
| M1 | 序号 车次 方向 线路 里程 |

七项开关（启用后底栏出现 [C]）：

| 项 | 作用 |
|---|---|
| <1> 过滤-机辆机待消息 | 忽略车次为空（`-----`）的消息 |

| <5> 过滤-较弱信号消息 | 弱信号（RSSI 低）消息不触发新消息提醒 |

### 5.8 [8] 公里标过滤 & 设置

```
1> 启用公里标过滤功能 [已禁用]
2> [上行] 列车报警    [已启用]
3> [下行] 列车报警    [已启用]
4> 屏蔽离去列车报警   [已禁用]
5> 显示列车到达时间   [已禁用]
```

## 6. 告警与提示音

设备使用无源蜂鸣器，可播放多音调旋律；「震动 / 联动」模式下马达同步动作。

### 6.1 操作提示音

| 事件 | 声音 |
|---|---|
| 按键 | 极短一声 |
| 确认 | 上行双音（低→高） |
| 取消 | 下行双音（高→低） |
| 返回 | 轻快下行双音 |
| 开机 | 明亮上行双音 |
| 射频故障 | 连续 7 声低沉短鸣 |

### 6.2 来车预警播报

| 方向 | 节拍 |
|---|---|
| 上行 | 短鸣 2 次（上行双音旋律） |
| 下行 | 长鸣 1 次（下行单音） |
| 其他/LBJ 时间 | 单次提示音 |

提示时长设为「长」时节拍放大 4 倍。**静音模式不播报；纯震动模式仅振动。**

## 7. 电源管理

| 状态 | 行为 |
|---|---|
| 开机电压 ≤3.40V | 拒绝开机：鸣响 10 声后自动关机 |
| 电压 ≤3.5V | 底栏显示 `低电量!`，自动禁用振动马达（防重启） |
| 电压 ≤3.3V | 鸣响 5 声（静音模式不响）后自动关机（需开启低电关机保护） |
| RTC 温度 ≥75℃ | 熄屏、鸣响 20 声后强制关机 |
| 充电中 | 电量区显示 `4.1V⚡` |

> 长期存放请保持 50% 左右电量；设备具备电源锁存电路，自动关机由固件控制释放。

## 8. 过滤器工作原理

一条消息从接收到告警需依次通过：

1. **条件过滤**（菜单 [7]）：空消息 / 未注册机辆 / 旧版 / 时间消息 / 弱信号
2. **上下行过滤**（菜单 [8] 的 2/3 项）：允许上/下行
3. **公里标过滤**（菜单 [8]）：`|列车公里标 − 本机公里标| ≤ 告警距离限制`
4. **离去过滤**（菜单 [8] 的 4 项）：列车已驶过本机公里标方向则不告警

通过全部过滤的消息才**存储并显示**；被过滤的消息静默丢弃。

底栏标志：`[K]`=公里标过滤启用，`[C]`=条件过滤启用，`[X]`=AFC 关闭。

## 9. 消息可靠性与乱码说明

LBJ 信号受距离、遮挡影响可能出现误码。若消息中出现以下内容，表示对应字段损坏：

- `<NUL>`、`NA`、`********` 或部分星号
- 车次显示 `-----`、公里标 `----.-`、速度 `---`、线路 `----`

建议：开启「过滤-空消息」「过滤-未注册机消息」减少无效显示；信号较弱区域可开启「过滤-较弱信号消息」。

## 10. 常见问题（FAQ）

**Q1：开机后时间不对？**
设备内置 RTC（PCF8563）断电保持时间。首次使用或 RTC 掉电时，请通过菜单 [5] 手动设置时间，或置于有 Wi-Fi 环境（SNTP 热点）自动校时。

**Q2：菜单不动了怎么办？**
菜单在 30/60/120 秒（菜单 [3] 可设）无操作后会自动退回主界面，不会影响后台接收。

**Q3：收不到消息？**
- 检查底栏是否出现红色 [X]（AFC 被关闭），进入菜单 [6] 重新开启
- 查看菜单 [10] 的当前频偏，偏移过大时说明机车电台频偏严重
- 确认过滤器设置（菜单 [7]/[8]）没有把目标消息过滤掉

**Q4：信号塔只有 1 格红色？**
RSSI 低于 -110dBm 左右，处于接收边缘，消息可能不完整。

**Q5：插入 TF 卡有用吗？**
本机型未焊接 SD 卡座，消息存储在机内 NVS（2000 条）。

**Q6：屏幕颜色发白/发暗？**
通过菜单 [3] 的「开启屏幕反显」切换色彩极性以匹配屏幕类型（IPS/TN）。
